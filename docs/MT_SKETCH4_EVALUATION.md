# MT-Sketch4-20K 首轮评测协议

本协议用于冻结 `MT-Sketch4-20K 1.0-review` 的第一次持续多任务测试。
本轮迁移已经固定的方法设置，不根据这份测试集的结果搜索超参数。
测试标签仅用于外部计分，不进入适应接口。

| 任务 ID | 图像数 | 原生类别数 | 类内样本数 |
|---|---:|---:|---:|
| `domainnet_sketch` | 5,000 | 345 | 4–15 |
| `imagenet_sketch` | 5,000 | 1,000 | 1–6 |
| `tuberlin` | 5,000 | 250 | 20 |
| `sketchy` | 5,000 | 125 | 40 |

数据根目录为 `data/MT-Sketch4-20K`，共20,000张。每张正式计分一次。
冻结清单SHA256为
`89f07bf643e621ecaef70010d51d2044d0750213aac19782324b27a615343570`。
详细来源、抽样、样本覆盖和审阅限制见
[数据说明](MT_SKETCH4_DATASET.md)。

## 输入、类别空间和状态

只测seed0，batch1，使用冻结 `balanced_round_robin`：按照表中任务顺序，
每个任务取一张，循环5000次。各任务内部保持冻结清单的类别名、原生相对路径排序。
不重新随机抽样、不截断、不打乱，不混入 `task_blocks` 的成绩。

任务ID已知，决定本次预测采用哪一套原生类别空间。标签为冻结
`metadata/classes.json` 的任务内 `class_index`，不能用 `native_class_id`
或ImageNet canonical index替代。1720是四套类别位置的总数，不是联合分类器类别数。
提示名称仅将原生 `class_name` 的下划线转为空格并去除首尾空白；
保留完整逗号同义词和重复显示名称，不替换为自然偏移实验的TPT词表。

四任务共同使用**单套可训练文本/视觉提示bank**。切换任务只更换冻结类别scaffold、
教师文本特征和该任务的固定文本路由；提示参数持续传递，不为每个任务保留独立提示副本。
优化器状态也持续传递。实现包含一个主AdamW和四个私有视觉专家AdamW，
各只创建一次；只有本图参与计算的专家更新，无梯度的专家不推进其参数步数。
主优化器覆盖全部文本专家及公共视觉参数，不能在任务切换时重建或清空动量。

## 预览和模型

在任何适应发生之前，分别读取每个任务最初64张图像，共256张已知任务的无标签预览。
四次路由都使用同一初始提示状态，以冻结学生无视觉提示的图像特征计算平均最大类别概率，
为该任务固定私有文本Top-2专家及混合权重。预览不使用真实标签或教师，不执行参数更新。
预览图像随后回到正式流，从全局第0张开始各计分一次；预览额外读取不算额外正式测试样本。
这是显式的lookahead预算，不是严格“当前图像到达前完全不可见”的在线协议。
类别排序也会使最初64张的类别分布不均匀，需在比较时保留这一事实。

| 项目 | 固定设置 |
|---|---|
| 学生 / 教师 | 冻结OpenAI CLIP ViT-B/16 / ViT-L/14 |
| 最终输出 | 当前图更新前学生概率argmax；无教师输出融合或校准 |
| 文本提示 | 4 context token；`a photo of a`；3共享+8私有专家；Top-2；共享权重0.5 |
| 视觉提示 | 每专家2 token；2共享+4私有专家；逐图Top-1；共享权重0.44 |
| 视觉路由 | `current_text_moe`；scale初值0.25 |
| 初始化 / 路由温度 | 专家噪声标准差0.02；额外视觉位置噪声0；两类路由温度1 |
| 更新门控 | 更新前学生最大类别概率≥0.815 |
| 更新步骤 | 每个入选图3步，目标、门控和该图路由在这3步内固定 |
| 损失 | 学生硬伪标签CE + 0.08 × 教师硬伪标签CE |
| 优化器 | AdamW；lr=7.5e-6；weight_decay=0；betas=(0.9,0.999)；eps=1e-8 |
| 其他 | 无shadow、任务特殊学习率、随机增强、额外视图、entropy/anchor损失 |

教师只用于辅助硬伪标签损失。数据解码采用EXIF转正、透明像素白底合成后转RGB，
随后使用CLIP确定性bicubic短边224缩放、224中心裁剪和标准归一化。
保持原本CUDA数值精度，外置提示参数为fp32；没有为了此次实验额外启用AMP或修改精度。

## 冻结对照和报告

对照从独立进程加载相同B/16权重，使用完全相同的20,000个成员、字节SHA、输入顺序、
图像解码和任务内类别映射。采用单模板 `a photo of a {class}`，batch1，
无教师、优化器、适应、预览或提示集成。不能把方法的随机专家初始化当作冻结CLIP基线。

主要指标为四任务Top-1准确率的等权平均，同时报告逐任务正确数、图像数、准确率、
相对冻结对照的百分点变化，以及入选图像数与更新步数。每个任务恰好5000张，
所以本轮微平均与宏平均数值相同。这里ImageNet-Sketch只有5000张自建子集，
并处于跨任务共享状态中，不能复用此前完整50,889张ImageNet-Sketch独立初始化的成绩。

冻结版本仍保留106张原生标签歧义标记和另外8张待人工审阅图像，二者不重叠。
标记并不等同于已确认错误标签；本轮不删图或改标签，不依据预测进行测试集清洗。
结果应标为 `1.0-review`，不能宣称已经专家全面清洗的正式榜单、全新未见测试集或同协议SOTA。

## 运行与完成记录

从源码目录安装项目，并单独准备冻结数据与官方CLIP权重后运行：

```bash
python scripts/evaluate_mtsketch.py --data-root /path/to/MT-Sketch4-20K --dry-run
python scripts/evaluate_mtsketch.py --data-root /path/to/MT-Sketch4-20K --model-cache /path/to/clip_weights --gpu 0 --output-dir outputs/mtsketch_seed0
python scripts/evaluate_mtsketch_zeroshot.py --data-root /path/to/MT-Sketch4-20K --model-cache /path/to/clip_weights --gpu 0 --output-dir outputs/mtsketch_zeroshot_seed0
```

每次运行使用新输出目录。dry-run不加载模型；正式推理需要CUDA。代码发布包不包含图片和权重，也尚未提供冻结20K数据包的公开下载入口；原始来源下载不能直接替代已固定的清单。准备要求见[DATA_DEPENDENCIES.md](../DATA_DEPENDENCIES.md)。

正式入口记录配置、源码/模型/输入哈希、逐图更新前预测、提示连续性、预览路由和持久优化器状态，并检查每图正式计分一次、每个入选图更新3步。历史运行使用其各自冻结的源码快照复核；当前代码目录整理不代表重新运行完整实验。已完成实测的可移植摘要见[RESULTS.md](RESULTS.md)。
